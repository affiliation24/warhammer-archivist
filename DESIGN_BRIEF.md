# Warhammer Archivist — бриф интерфейса для дизайнера

Документ описывает текущий интерфейс и его функционал «как есть» (по коду `src/tui.py` — TUI, `src/ui.py` — оформление и звук, справочно `src/persona.py` и `src/cli.py`), чтобы на его основе можно было придумать новый дизайн. Всё фактическое: цвета, зоны, тексты, клавиши, поведения.

Актуализировано: 2026-11-05 (по коду на эту дату).

---

## 1. Продукт и атмосфера

**Warhammer Archivist** — терминальный «архив Адептус Механикус»: чат-бот с RAG-поиском по корпусу книг и вики Warhammer 40,000. Игрок задаёт вопрос, система ищет релевантные фрагменты в локальной базе (ChromaDB + BM25 + reranker), а DeepSeek пишет ответ «в образе» архивариуса-техножреца.

Интерфейс — полноэкранный TUI в терминале (фреймворк Textual 8.2.8 поверх Rich). Принципиально: **растровые клетки моноширинного шрифта, а не пиксели**. Стилистика — «готик-индастриал, тёмный HUD»: тёмно-зелёные фоны, латунь, пергаментная кость, тусклая кровь, сталь, фосфорно-зелёный акцент и янтарная статус-строка. Никаких изображений и шрифтов — только ANSI/TrueColor, Unicode-глифы и рамки из box-drawing-символов (двойные `double`, тяжёлые `heavy`).

Сцена «широкого экрана»: контент центрируется, максимальная ширина рабочей сцены — 132 клетки, по бокам — декоративные «гуттеры» с шумовым паттерном. Внутри — журнал чата в двойной рамке, справа панель источников, янтарная статус-строка, строка ввода и footer с клавишными чипами.

Отдельно есть **опциональный CRT-слой** (переключатель «Эффекты CRT»): бегущая скан-линия, мерцание заголовков, «скрэмбл» обновляемых значений, пульсация статус-строки. Подробности — раздел 6.

Заголовок окна терминала: `Warhammer Archivist — Терминал Адептус Механикус`.

Кроме TUI существует **fallback-CLI** (для пайпов/скриптов и машин без Textual) со своим баннером и сплэшем — справочно описан в разделе 11.

## 2. Цветовая палитра

Палитра общая для всех тем; темы меняют фон/поверхности/панели и два декоративных токена (`frame`, `scanline`) — см. раздел 3.

| Роль | Имя токена | HEX |
|---|---|---|
| Латунь (акценты, клавиши-чипы, заголовки баннера) | `brass` | `#d7af5f` |
| Кость/пергамент (основной светлый текст) | `bone` | `#ffd7af` |
| Тусклая кровь (разделители, ошибки, warning) | `blood` | `#af5f5f` |
| Сталь (скроллбар, неактивное, гуттер-шум) | `iron` | `#444444` |
| Тусклая латунь (второстепенный латунный, подсказки footer) | `dull-brass` | `#af8700` |
| Яркий зелёный (success-семантика Textual) | `green` | `#00ff00` |
| Тёмно-зелёный (тело ответов бота) | `dark-green` | `#1e9e1e` |
| Приглушённый зелёный (подсказки, эхо, метаданные) | `dim-green` | `#6f9f6f` |
| **Фосфор** (шапка, заголовки рамок, лента-заголовок ответа, подсветка списков, primary-кнопка) | `phosphor-bright` | `#8dff3a` |
| **Янтарь** (фон статус-строки, чип «Палитра» в footer) | `alert` | `#ff7a1a` |

Производные цвета (не токены, заданы в CSS): текст на янтарной статус-строке `#3a2200` (обычный) / `#0d0800` (жирный, занято); пульсация статус-строки `#d6660f`; текст на фосфорных плашках `$bg` (цвет фона текущей темы) и `#061200` при вспышке.

Типографика: моноширинный шрифт терминала; «жирность» и цвет — единственные средства выделения. Используемые глифы: `>`, `✓`, `▌` (курсор этапа прогрева), `┌ ┐` (тег сеанса), `·`, `•`, `═`, `╱ ╲` (арки баннеров), `▓ ░` (прогресс), `░▒▓▚▞` (шум гуттеров), `▓▒░█▚▞◇◈┼╳` (скрэмбл CRT), `⚙` (орнамент баннера CLI), брайлевские кадры спиннера (`⠋⠙⠹⠸⠼⠴⠦⠧⠇⠏`), двойные/тяжёлые box-drawing рамки.

## 3. Темы

Три темы; **акцентная палитра из раздела 2 неизменна**, с темой меняются фон/поверхности/панели + цвет рамок (`frame`) и цвет скан-линии (`scanline`):

| Тема | фон `$bg` | поверхность `$surface` | панель `$panel` | текст `$fg` | рамки `$frame` | скан-линия `$scanline` |
|---|---|---|---|---|---|---|
| **Механикус** (по умолчанию) | `#0a0c0a` | `#0f130f` | `#161d16` | `#ffd7af` | `#445544` | `#1a2b12` |
| **Механикус тёмный** | `#030403` | `#080a08` | `#0e120e` | `#e8c9a5` | `#5f8c3a` | `#243d18` |
| **Механикус угольный** | `#101308` | `#161c0f` | `#1d2512` | `#d9bfa0` | `#3a4434` | `#0f1a0a` |

Все три — тёмные, с зелёным подтоном. «Тёмный» — почти чёрный; «угольный» — тёмно-оливковый (заметно зеленее остальных); «Механикус» — между ними. Рамки и скан-линия меняются в тон теме.

## 4. Главный экран — зоны сверху вниз

```
┌─ ШАПКА: ARCHIVE TERMINAL · ADEPTUS MECHANICUS ────────────────────────────────┐
│        ┌ ПАРАМЕТРЫ СЕАНСА · Machine Spirit awakened. ┐                          │
├────────────────────────────────────────────────────────────────────────────────┤
│ ░▒▓ │ ╔═ ЖУРНАЛ ══════════════════════╗ │ ╔═ ИСТОЧНИКИ ПОСЛЕДНЕГО ═╗ │ ░▒▓     │
│     │ ║ баннер / лента чата           ║ │ ║ 1. Название        ║ │           │
│     │ ║ (внутри — скан-линия при CRT) ║ │ ║    Глава · релев.  ║ │           │
│     │ ║                              ║ │ ╠─ ЭПОХА: M30-31 ───────╣ │           │
│     │ ║                              ║ │ ║ ФРАГМЕНТОВ: 12      ║ │           │
│     │ ╚══════════════════════════════╝ │ ╚═════════════════════╝ │           │
├─ СТАТУС-СТРОКА (янтарная): Готов к приёму запроса. ─────────── ◐ ─┤
├─ ВВОД: > [ Вопрос к архиву…  (/help — справка · Tab — автодополнение) ] ──────┤
└─ FOOTER: [Ctrl+F] [Ctrl+T] [Ctrl+K] [Ctrl+S] [Ctrl+U] [Ctrl+D] [Ctrl+L] [F1] [Ctrl+Q] ┘
```

Рабочая сцена (`#main`) центрируется, ширина = `min(132, ширина терминала)`; при терминале шире 132 по бокам появляются гуттеры (`FillerPanel`): детерминированный псевдослучайный шум из символов ` ░▒▓▚▞` цветом «сталь» с прозрачностью 0.35.

### 4.1 Шапка

Высота 3 (две строки контента + линия рамки снизу), фон `$bg`, снизу линия `solid $frame`:

```
ARCHIVE TERMINAL · ADEPTUS MECHANICUS            ← фосфор, жирный, по центру
┌ ПАРАМЕТРЫ СЕАНСА · Machine Spirit awakened. ┐  ← приглушённый зелёный, по центру
────────────────────────────────────────────────  ← рамка $frame
```

- Строка 1 **печатается посимвольно** при каждом запуске (1 символ / 0.03 с), после чего появляется строка 2 — тег сеанса с приветствием.
- Приветствие выбирается один раз на сессию из пяти вариантов:
  - *Machine Spirit awakened.*
  - *Cognition matrix online.*
  - *Sacred circuits humming.*
  - *The Omnissiah watches.*
  - *Binary rites complete.*

### 4.2 Журнал (чат)

Рамка **двойная** (`double`) цвета `$frame`; заголовок рамки ` ЖУРНАЛ ` — фосфор, жирный. Внутренние отступы 1 клетка. Вертикальный скроллбар 1 клетка: трек — «панель», ползунок — `$frame`, при наведении/активности — фосфор.

**Приветственный баннер при старте** появляется после печати шапки; строки монтируются приглушённо-зелёными и **проявляются цветом по одной каждые 0.12 с**. Варианты зависят от ширины:

- **≥ 100 клеток** — полная версия с аркой:
  ```
      ╱       ╲            ← сталь
    •═════════════•        ← кровь
    ARCHIVE TERMINAL       ← латунь
    ADEPTUS MECHANICUS     ← кость

    Machine Spirit awakened.                                    ← приглушённый зелёный
    Вводите вопрос внизу. /help — справка, /sources — источники.  ← приглушённый зелёный
  ```
- **60–99 клеток** — без арки: `ARCHIVE TERMINAL` (латунь), `ADEPTUS MECHANICUS` (кость), клёпаная линия `•═════════════•` (кровь), пустая строка, приветствие и подсказка.
- **< 60 клеток** — одна строка `ARCHIVE TERMINAL` (латунь).

**Сообщения в журнале:**

- Вопрос пользователя — эхо-строка `> текст вопроса` приглушённым зелёным.
- Ответ бота: сначала **лента-заголовок** (`hl-band`) — плашка на всю ширину журнала: фон фосфор `#8dff3a`, текст цветом фона темы, жирный, отступы по 1 строке сверху/снизу. Заголовок — 3–7 слов (первая строка ответа модели вида `**Заголовок**`). Далее пустая строка и тело рассказа **тёмно-зелёным** (`#1e9e1e`); `**жирные акценты**` внутри текста — тёмно-зелёный жирный. Стиль — «живой архивариус»: проза от первого лица, без шаблонных списков. Если данных мало — короткая честная реплика без заголовка и ленты.
- После каждого ответа — приглушённая подсказка: `(наберите /sources, чтобы увидеть источники ответа)`.
- При включённом CRT лента-заголовок периодически **мерцает** (см. раздел 6).

**Автопрокрутка:** журнал скроллится к новому сообщению только если пользователь уже был внизу; если листал историю — позиция не сбивается.

### 4.3 Панель источников

Справа, ширина 40 клеток, двойная рамка `$frame`, заголовок ` ИСТОЧНИКИ ПОСЛЕДНЕГО ОТВЕТА ` — фосфор, жирный. Фон — «поверхность».

**Показ:** по умолчанию скрыта. Если пользователь ни разу не переключал её вручную, панель **автоматически показывается при ширине сцены ≥ 120** и скрывается при сужении. Ручное переключение (Ctrl+F, `/sources` или переключатель в настройках) запоминается в конфиг и отключает автопоказ до следующего запуска.

**Список фрагментов последнего ответа:**

```
1. Название источника          ← номер латунью, название костью
   Глава · релевантность 0.87  ← приглушённый зелёный
2. ...
```

Между пунктами — пустая строка. Пока вопросов не было — заглушка: «Источников пока нет — сначала задайте вопрос.»

**Блок данных сеанса** внизу панели (высота 5, отделён линией `$frame` сверху, фон «поверхность») — четыре строки, выровненные вправо, формат `МЕТКА: значение` (метка — приглушённый зелёный, значение — кость):

- `ЭПОХА:` — `M30-31` / `M41-42` (по большинству фрагментов) или `—`
- `ФРАГМЕНТОВ:` — число источников последнего ответа
- `РЕЛЕВАНТНОСТЬ:` — максимальная оценка reranker'а с двумя знаками
- `ТЕМА:` — имя текущей темы

Значения обновляются после каждого ответа (и при смене темы); при включённом CRT новое значение «проявляется» скрэмблом из случайных глифов.

### 4.4 Статус-строка

Высота 1, **янтарный фон `$alert`** (`#ff7a1a`), текст тёмно-коричневый (`#3a2200`) с прозрачностью 0.65. Справа — спиннер (Textual `LoadingIndicator`, ширина 2, тёмный), виден только при занятости.

- При занятости: прозрачность 1, текст `#0d0800` жирным.
- При любой **смене текста статуса** строка вспыхивает фосфором (фон `$phosphor-bright`, текст `#061200`) на 0.15 с — работает и без CRT.
- При занятости + включённом CRT фон пульсирует между `$alert` и `#d6660f` каждые 0.45 с.

Основные статусы:

- «Готов к приёму запроса.»
- «Машинный Дух обрабатывает запрос...»
- «Машинный Дух отвечает...»
- «Протокол поиска завершён.»
- «Требуется выбор эпохи (↑/↓, Enter).»
- «Журнал очищен.»
- «Панель источников открыта. / скрыта.»
- «Источников пока нет — сначала задайте вопрос.»
- «Тема: Механикус.» (и др.)
- «Машинный Дух ещё обрабатывает предыдущий запрос...»
- «Ошибка обработки запроса.»
- «Ошибка прогрева. См. журнал.»
- «Неизвестная команда. /help — список команд.»
- «Эпоха выбрана: …»
- Автодополнение: «Дополнено: `/sources` — источники последнего ответа», «Дополнено: `/so` · Tab — следующий вариант», «Нет команд по «`/x`». Доступно: `/clear /exit /help /quit /sources /theme`.»

### 4.5 Строка ввода

Высота 4 (контент + линия рамки сверху), фон «поверхность», сверху **двойная** линия `$frame`. Слева промпт `>` (фосфор, жирный, ширина 2), справа поле ввода, плейсхолдер: «Вопрос к архиву…  (/help — справка · Tab — автодополнение)». Текст — кость; при фокусе фон меняется на `$bg`; во время обработки поле блокируется и становится приглушённым.

### 4.6 Footer

Высота 2, фон «панель», сверху линия `solid $frame`. Ряд «клавишных чипов»: клавиша в квадратных скобках на стальном фоне латунью + описание костью; базовый цвет самого footer — тусклая латунь:

```
Ctrl+F Источники  Ctrl+T Тема  Ctrl+K Палитра  Ctrl+S Настройки  Ctrl+U Вверх
Ctrl+D Вниз  Ctrl+L Очистить  F1 Помощь  Ctrl+Q Выход
```

Чип «Палитра» — единственный с **янтарным** фоном `$alert` и тёмным текстом. Footer показывает биндинги текущего экрана: в модалках меняется на их клавиши (например, `Esc Закрыть`).

## 5. Модальные окна

Общее: по центру, ширина 66 клеток, **тяжёлая** (`heavy`) рамка `$frame`, фон «поверхность», отступы 1×2. Заголовок рамки — фосфор жирным на фоне `$bg`. Закрытие — Esc.

### 5.1 Настройки (Ctrl+S)

```
┌─ НАСТРОЙКИ ТЕРМИНАЛА ─────────────────────────────────────────┐
│ Звуковые сигналы                                   [■]        │
│ Эффект печатной машинки                            [■]        │
│ Фоновая музыка                                     [ ]        │
│ Панель источников                                  [ ]        │
│ Эффекты CRT                                        [■]        │
│ Тема (палитра не меняется — только фон):                      │
│   Механикус · Механикус тёмный · Механикус угольный            │
│                                                  [ Готово ]   │
└────────────────────────────────────────────────────────────────┘
```

- **5 переключателей** (Textual Switch, слайдер с анимацией; включён — фосфор): **Звуковые сигналы**, **Эффект печатной машинки**, **Фоновая музыка**, **Панель источников**, **Эффекты CRT**.
- Список тем: выделенный пункт — фосфорная плашка с тёмным текстом, выбранный — фосфорный жирный.
- Кнопка **«Готово»** (primary: фосфорный фон, тёмный текст, прижата вправо).
- Изменения применяются мгновенно и сохраняются в `terminal_config.json` — шесть ключей: `theme`, `sounds`, `typing`, `music`, `panel`, `crt`. События переключателей при первоначальной установке значений игнорируются (никаких повторных запусков музыки/CRT).
- По умолчанию: тема `mechanicus`, звуки вкл., печатная машинка вкл., музыка вкл., панель скрыта, CRT **вкл**.

### 5.2 Справка (F1)

Заголовок `СПРАВКА`, таблица горячих клавиш: клавиша латунью в колонке фиксированной ширины 24, описание костью с переносом по словам, отбивка `  ` сталью. Снизу: «Esc / Enter — закрыть». Список клавиш — в разделе 8.

### 5.3 Выбор эпохи

Появляется, когда поиск нашёл данные и по Ереси Хоруса, и по современному Империуму:

```
┌─ НАЙДЕНЫ ДАННЫЕ ИЗ РАЗНЫХ ЭПОХ ───────────────────────────────┐
│ Реливантные записи относятся к разным эпохам вселенной.        │
│ Выберите эпоху (↑/↓, Enter):                                   │
│   Ересь Хоруса / Великий Крестовый поход, ~M30-31              │
│   современный Империум, ~M41-42                                │
│ Esc — отменить вопрос                                          │
└────────────────────────────────────────────────────────────────┘
```

Это `SelectionList` (выделенный пункт — фосфорная плашка с тёмным текстом). Выбор сразу продолжает запрос (в журнал пишется «Эпоха выбрана: …»); Esc отменяет вопрос (в журнале — «Уточнение эпохи отменено.»).

### 5.4 Командная палитра (Ctrl+K / Ctrl+P)

Стандартное поисковое поле «Команда…» с живой фильтрацией по 8 командам:

- Показать или скрыть источники (Ctrl+F)
- Сменить тему (Ctrl+T)
- Настройки: звук, печать, музыка (Ctrl+S)
- Справка по клавишам (F1)
- Прокрутить журнал вверх (Ctrl+U)
- Прокрутить журнал вниз (Ctrl+D)
- Очистить журнал (Ctrl+L)
- Выйти (Ctrl+Q)

Палитра переоформлена: контейнер 66 клеток с тяжёлой рамкой на «поверхности», поле ввода на «панели», результаты на «поверхности», выделенный пункт — фосфорная плашка с тёмным текстом. Подложка — затемнение фона (60%).

### 5.5 Экран прогрева (только холодный старт, модели не в кэше)

Отдельный экран: коробка шириной 62 с тяжёлой рамкой, заголовок «Пробуждение Машинного Духа...» фосфором жирным, список из 4 этапов:

```
Пробуждение Машинного Духа...

  ✓ Активация архивной базы данных
  ▌ Синхронизация BM25-инде

        [▓▓▓▓░░░░] 42%
```

- Пройденные — `✓` латунью, текущий — маркер `▌` костью + **печатающийся текст этапа** (по 2 символа каждые 0.03 с), будущие — приглушённые.
- Прогресс-бар 24 клетки (`▓`/`░`, латунь) + проценты костью. Проценты — интерполяция по ожидаемой длительности этапов `[1, 4, 5, 90]` с, внутри этапа рост ограничен 97% до его фактического завершения. Обновление каждые 0.15 с.
- Этапы: «Активация архивной базы данных», «Инициализация нейросети эмбеддингов», «Синхронизация BM25-индекса», «Калибровка когнитивного фильтра».
- После завершения в журнал пишется: «Машинный Дух пробуждён. Архив открыт.»

## 6. Ключевые интеракции

**Цикл вопроса:** ввод → Enter → эхо вопроса в журнал → поле блокируется, статус «Машинный Дух обрабатывает запрос...», янтарная строка становится жирной, справа спиннер → поиск и генерация в фоновом потоке (интерфейс не зависает) → обновление панели источников и данных сеанса → звук ответа → ответ «печатается». При неоднозначности эпох посреди цикла — модалка выбора (5.3).

**Эффект печатной машинки:** печатаются и лента-заголовок, и тело ответа — порциями по 4 символа (~12 мс на символ); **любая клавиша мгновенно допечатывает весь ответ**. Отключается в настройках (тогда текст появляется сразу).

**Ошибки** выводятся в журнал (приглушённый зелёный): исчерпаны токены DeepSeek, доступ запрещён, сетевые сбои, «Ошибка обращения к DeepSeek: …». Статус — «Ошибка обработки запроса.», звук ошибки. Ошибка прогрева — кровавым текстом в журнале + статус «Ошибка прогрева. См. журнал.».

**Вопросы о личности** («кто ты?» и т.п.) отвечаются мгновенно каноническими репликами-заготовками (3 варианта в `persona.py`), без RAG-поиска, со статусом «Машинный Дух отвечает...».

**История ввода:** ↑/↓ листают предыдущие вопросы; текущий черновик сохраняется и возвращается вниз списка.

**Темы:** Ctrl+T циклически переключает; в настройках — точный выбор. Смена обновляет строку `ТЕМА:` в данных сеанса и сохраняется.

**Автодополнение по Tab** (только когда строка начинается с `/`): первый Tab дополняет до общего префикса, следующие перебирают варианты по кругу, Shift+Tab — назад; в статусе показывается подсказка/описание команды. Вне командного контекста Tab/Shift+Tab работают как обычно — перевод фокуса.

**Команды чата:** `/clear` — очистить журнал, `/exit` и `/quit` — выход, `/help` — справка, `/sources` — переключить панель источников, `/theme` — следующая тема. Неизвестная команда — реплика в журнале + статус «Неизвестная команда. /help — список команд.».

**CRT-эффекты** (переключатель «Эффекты CRT», по умолчанию включены):

- **Скан-линия** — полоса 1 клетка цветом `$scanline` поверх журнала, медленно ползёт сверху вниз (полный проход ~5 с, шаг 0.12 с).
- **Мерцание** — лента-заголовок ответа случайно (раз в 3–8 с) перекрашивается в приглушённый зелёный на 0.06–0.1 с, имитация фосфорного «дыхания».
- **Скрэмбл значений** — при обновлении данных сеанса новые символы проявляются через случайные глифы `▓▒░█▚▞◇◈┼╳` (2 символа за 0.045 с).
- **Пульсация** — статус-строка при занятости мигает между янтарным и `#d6660f` (0.45 с).
- Вспышка статус-строки при смене текста (0.15 с) и анимации шапки/баннера работают **независимо** от переключателя CRT.

## 7. Звуковая идентичность

- **Событийные звуки** (короткие, папка `sounds/`): запуск (`startup`), готовый ответ (`answer`), выход (`exit`), ошибка (`error`). Выключаются переключателем «Звуковые сигналы».
- **Фоновая музыка** — зацикленный трек *Warhammer 40,000: Mechanicus — 02 Caestus Metalican*, играет всю сессию. Включается/выключается переключателем. Повторный старт при уже играющей музыке игнорируется; при запуске гасятся «осиротевшие» процессы музыки от прошлых сессий.
- Воспроизведение — системными плеерами (`afplay` на macOS, PowerShell/WPF на Windows, `mpg123`/`ffplay`/`mpv`/`cvlc` на Linux), без библиотек.

## 9. Технические ограничения — важно для дизайнера

- **Терминал, не веб**: сетка моноширинных клеток; «пиксель» — одна клетка символа. Адаптивность только по числу колонок/строк; минимум для комфорта ~80×24.
- Нельзя: кастомные шрифты, картинки, иконки (только Unicode-глифы), произвольное позиционирование вне сетки, кадровые анимации (только смена символов/цветов по таймерам; слайдер Switch — единственная плавная анимация Textual).
- Рамки рисуются box-drawing-символами и **съедают строку внутри высоты виджета** (поэтому шапке нужно 3 строки, footer'у — 2, строке ввода — 4: контент + линия рамки).
- Сцена ограничена 132 клетками и центрируется; при ширине сцены ≥ 120 панель источников показывается автоматически (если пользователь не выбрал режим вручную). Баннер журнала адаптируется тремя ступенями (раздел 4.2).
- Интерфейс должен оставаться **клавиатурно-первым**: весь флоу обязан проходиться клавишами, мышь вторична.
- Только тёмные темы (светлая тема лор-продукту не предполагается, но и не запрещена).
- Текст — русский; интерфейсные реплики стилизованы под «техножреческий канцелярит» («Машинный Дух», «Протокол поиска», «Калибровка когнитивного фильтра»).
- Настроек сохраняется шесть (тема, звуки, печатная машинка, музыка, панель, CRT) в `terminal_config.json` рядом с проектом.

## 10. Боли текущего вида (отправная точка для нового дизайна)

1. **Динамика спрятана за переключателем**: самые выразительные приёмы (скан-линия, мерцание, скрэмбл) — CRT-слой, который легко не заметить/выключить; статичный вид заметно беднее.
2. **Статус-строка выбивается из палитры**: янтарь `#ff7a1a` и фосфорная вспышка — самые «не-готические» пятна экрана; они работают как HUD, но спорят с латунью/кровью/сталью.
3. **Каждый запуск платит за интро**: печать шапки (~1.1 с) + построчное проявление баннера (0.12 с/строка) нельзя пропустить.
4. **Данные сеанса** (эпоха, фрагменты, релевантность) живут только внизу панели источников; при скрытой панели они невидимы, хотя это ценная обратная связь о работе RAG.
5. **Баннер деградирует с шириной**: арка есть только от 100 клеток, ниже 60 остаётся одна строка — фирменная графика исчезает на узких терминалах.
6. **Три темы по-прежнему различаются слабо**: меняются светлота фона и оттенок рамок, но на глаз ступени почти неразличимы; «угольный» может читаться как «грязный» фон, а не как осознанная тема.
7. **Прогресс прогрева — интерполяция** по ожидаемым секундам [1/4/5/90]: на медленных носителях процент может висеть на 97% до фактического завершения этапа — ощущение зависания остаётся.
8. **Иерархия зон держится на цвете, а не на форме**: рамки журнала и панели источников одинаково двойные и одного цвета `$frame`; шапка/статус/footer — по-прежнему три горизонтальные полосы, различающиеся в основном заливкой.

## 11. CLI-fallback (справочно)

Если терминал не интерактивный или Textual недоступен, запускается построчный CLI со своей «витриной»:

- **Сплэш при старте**: на 1.8 с крупная надпись `MECHANICUS` блочным шрифтом 5×5 (заливка `▓`), под буквами — «стекающие капли» `▓ → ▒ → ░` случайной длины; буквы — ярко-зелёные, капли — приглушённые.
- **Баннер** (перерисовывается на каждом действии): трёхступенчатая арка `╱…╲` сверху и зеркально снизу (сталь), «клёпаные» линии `•═══•` (кровь), разряженные заголовки `ARCHIVE TERMINAL` / `ADEPTUS MECHANICUS` (латунь/кость), орнамент из семи шестерён `⚙` (сталь), приветствие (приглушённый зелёный). Под ним — подсказки команд: `/exit — прервать связь с терминалом`, `/sources — явить источники последнего ответа`.
- Ввод — построчный промпт `> `; Tab-автодополнение `/exit`, `/quit`, `/sources` через readline (macOS — libedit-обвязка). Ответы печатаются посимвольно тёмно-зелёным (12 мс/символ), звёздочки `**` снимаются (жирного в CLI нет). Тот же экран прогрева и меню выбора эпохи стрелками, что и в TUI.
