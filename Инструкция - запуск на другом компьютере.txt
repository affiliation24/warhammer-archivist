ЗАПУСК БОТА НА ДРУГОМ КОМПЬЮТЕРЕ (С ФЛЕШКИ MEDJAY)
==============================================

Всё, что нужно боту (код, база данных, модели), лежит на флешке в папке
warhammer-archivist. Ничего на новом компьютере не остаётся после того,
как флешку вынули. Никакие команды вручную набирать не нужно — везде
готовые файлы для двойного клика.


ЧАСТЬ 1. ЕСЛИ ЭТО MAC (Apple Silicon M1/M2/M3/M4 или старый Intel)
--------------------------------------------------------------------------

Файл "Warhammer Chat.command" сам определяет тип процессора и запускает
подходящую версию — действия одинаковые для обоих типов Mac.

1. Вставь флешку MEDJAY в компьютер.
2. Открой флешку в Finder → папка warhammer-archivist.
3. Дважды кликни на файл "Warhammer Chat.command".
4. Бот запустится в новом окне терминала. Чтобы выйти — набери /exit и
   нажми Enter.
5. Перед тем как вынимать флешку — сначала закрой бота (/exit), подожди
   пару секунд, и только потом вытаскивай флешку из компьютера.

Если Mac спросит "вы уверены, что хотите открыть это приложение" — нажми
"Открыть" (это стандартное предупреждение для файлов не из App Store).

Если это первый раз именно на Intel-Mac — сначала понадобится разовая
установка, как для Windows: открой Терминал, перетащи
в его окно файл "scripts/setup_portable.sh" с флешки, допиши после него
через пробел путь к флешке (обычно "/Volumes/MEDJAY") и нажми Enter.
Подожди, пока установится (нужен интернет), после этого пункты 1-5 выше
будут работать и дальше через простой двойной клик.


ЧАСТЬ 2. ЕСЛИ ЭТО WINDOWS
--------------------------------------------------------------------------

На Windows один раз (на каждом новом компьютере) нужно установить нужные
программы — это делается один раз, минут 5-10, дальше можно просто
запускать. Тоже всё через двойной клик, вводить ничего не нужно.

Шаг 1 — установка (один раз на этом компьютере, нужен интернет):

1. Вставь флешку MEDJAY.
2. Открой флешку в "Проводнике" → папка warhammer-archivist → папка
   scripts.
3. Дважды кликни на файл "setup_portable.bat".
4. Если Windows покажет предупреждение "Windows защитила ваш компьютер" —
   нажми "Подробнее", затем "Выполнить в любом случае" (это стандартное
   предупреждение для файлов не из Microsoft Store).
5. Откроется чёрное окошко — подождать, пока всё установится (внизу
   появится "Готово" и оно попросит нажать любую клавишу).

Шаг 2 — запуск бота:

1. В папке warhammer-archivist (не в scripts, а на уровень выше) дважды
   кликни на файл "Warhammer Chat.bat".
2. Чтобы выйти — набери /exit и нажми Enter.

Шаг 3 — ПЕРЕД тем, как вынимать флешку (важно!):

1. Закрой бота (/exit), если он ещё открыт.
2. В папке scripts дважды кликни на файл "end_session.bat".
3. Он сам всё закроет и подчистит, и в конце скажет, что флешку можно
   вынимать (или отключит её сам). Нажми любую клавишу, когда попросит.


ЧАСТЬ 3. ЕСЛИ ЭТО LINUX
--------------------------------------------------------------------------

На Linux двойной клик может не запустить терминал (зависит от дистрибутива
и его настроек) — поэтому здесь понадобится один раз открыть терминал
самостоятельно. Дальше — как и везде, ничего вручную не печатается, кроме
самого пути к флешке.

Шаг 1 — установка (один раз на этом компьютере, нужен интернет):

1. Вставь флешку, узнай, куда она примонтировалась (обычно
   /media/имя-пользователя/MEDJAY или похоже — видно в файловом
   менеджере).
2. Открой Терминал.
3. Перетащи в окно терминала файл "scripts/setup_portable_linux.sh" с
   флешки (сама программа-терминал допишет туда полный путь к файлу) —
   после этого допиши через пробел путь к флешке и нажми Enter, получится
   что-то вроде:

     /media/user/MEDJAY/warhammer-archivist/scripts/setup_portable_linux.sh /media/user/MEDJAY

4. Подожди, пока всё установится.

Шаг 2 — запуск бота:

1. Попробуй дважды кликнуть на файл "Warhammer Chat.sh" в папке
   warhammer-archivist на флешке.
2. Если ничего не произошло (или открылся текстовый редактор вместо
   запуска) — открой Терминал, перетащи в него тот же файл
   "Warhammer Chat.sh" и нажми Enter.
3. Чтобы выйти — набери /exit и нажми Enter.

Шаг 3 — перед тем как вынимать флешку:

1. Закрой бота (/exit).
2. Подожди пару секунд и через файловый менеджер выбери "Извлечь"/"Eject"
   для флешки, только потом вынимай её физически.


ВАЖНО ЗНАТЬ
--------------------------------------------------------------------------

- Первый запуск на новой машине может занять больше времени — бот сам
  показывает, что происходит (полоску загрузки с процентами), это
  нормально, просто нужно подождать.
- Для ответов бота нужен интернет (сам поиск по книгам работает без сети,
  но финальный ответ генерирует внешний сервис — Groq).
- Ключ доступа к этому сервису (GROQ_API_KEY) уже лежит в файле .env на
  флешке — трогать его не нужно.
